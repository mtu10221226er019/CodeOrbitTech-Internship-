# CodeOrbitTech Internship – Simple REST API

## Project Description
A simple REST API built using Node.js and Express.js to manage user records.

## Technologies Used
- Node.js
- Express.js
- JavaScript
- CORS
- dotenv
- Git and GitHub

## Features
- View all users
- View user by ID
- Add a new user
- Update user details
- Delete a user
- Handle invalid API routes

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/mum10221226er019/CodeOrbitTech-Internship-.git
   ```

2. Open the project folder:
   ```bash
   cd CodeOrbitTech-Internship-
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the server:
   ```bash
   npm run dev
   ```

5. Open:
   `http://localhost:5000`

## API Endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| GET | / | Home |
| GET | /api/users | View users |
| GET | /api/users/:id | View one user |
| POST | /api/users | Add user |
| PUT | /api/users/:id | Update user |
| DELETE | /api/users/:id | Delete user |
